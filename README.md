# Power Analytics — Sprint 2

Portal de Gestão do Suporte da Power System, pronto para GitHub Pages.

## O que esta versão lê

- Abas mensais `NPS Jan`, `NPS Fev`, etc.
- Aba `NPS Trim` ou `NPS Trimestral`.
- A:G: atendimentos, avaliações, percentual, média, descontos e média final.
- I: pontuação mensal da caixinha.
- J: bonificação trimestral por atendente e total.
- Tabela-base iniciada em A14 para auditoria.

## Atualização

Substitua ou adicione o Excel em `data/ANO/` e atualize `data/manifest.json`.

## Publicação

Envie todo o conteúdo desta pasta para a raiz do repositório GitHub e mantenha o GitHub Pages configurado para `main / (root)`.
