# Power Analytics — Sprint 3.7

Esta versão amplia o módulo **Evolução** com análises mensais e trimestrais.

## Novos controles

- Periodicidade:
  - Mensal
  - Trimestral
- Indicador:
  - Atendimentos
  - Avaliações
  - Taxa de avaliação
  - Média final
  - Pontuação da Caixinha
- Colaborador:
  - Equipe completa
  - Colaborador individual

## Recursos

- gráfico mensal de janeiro a julho de 2026;
- evolução individual dos colaboradores;
- tabela com os valores utilizados no gráfico;
- variação percentual em relação ao período anterior;
- cartões com último resultado, melhor período e comparação recente.
